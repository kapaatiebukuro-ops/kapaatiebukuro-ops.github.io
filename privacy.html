プライバシーポリシー

最終更新日：2026年8月19日

「KappaOS チャンネル分析ツール」（以下「本ツール」）は、YouTubeチャンネル運営者本人が、 自分自身のチャンネルの分析データを読み取るために使用する個人用のプログラムです。 本ツールにおける情報の取り扱いを以下のとおり定めます。

1. 運営者

個人（YouTubeチャンネル「カッパえんちょー【公式】」「カッパ恨島」運営者）

2. 利用者の範囲

本ツールは一般に提供されるサービスではありません。利用者は運営者本人のみであり、 運営者本人が所有・管理するYouTubeチャンネルに対してのみ使用します。

3. 取得する情報

Googleアカウントで認証を行った場合、以下の情報をYouTube APIから取得します。

権限取得する情報
https://www.googleapis.com/auth/yt-analytics.readonly 視聴回数、総再生時間、平均視聴時間、視聴者維持率、登録者の増減、 トラフィックソース、視聴者層など、YouTube Analytics のレポート情報
https://www.googleapis.com/auth/youtube.readonly 自分のチャンネルおよび動画の公開情報、動画に寄せられたコメント

いずれも読み取り専用の権限です。本ツールは動画、コメント、チャンネル設定に対する 作成・変更・削除を一切行いません。

4. 情報の利用目的

取得した情報は、運営者が自分のチャンネルの状況を把握し、今後の動画制作の内容や公開方法を 検討するためだけに利用します。それ以外の目的には利用しません。

5. 情報の保存

  • 認証トークンおよび取得したデータは、運営者本人のパソコンのローカル領域にのみ保存します。
  • 外部のサーバー、クラウドストレージ、データベースへ送信・保管することはありません。
  • 本ツールはウェブサービスを提供しておらず、第三者がデータへアクセスすることはできません。

6. 第三者への提供

取得した情報を第三者へ提供、販売、共有することはありません。 広告配信、行動解析、機械学習モデルの学習など、第三者のサービスへの受け渡しも行いません。

7. Google API サービスユーザーデータポリシーへの準拠

本ツールによるGoogle APIから受け取った情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に準拠します。

8. アクセス権の取り消し

本ツールへ付与した権限は、Googleアカウントの 「サードパーティ製のアプリとサービス」 からいつでも取り消すことができます。取り消し後、本ツールはデータを取得できなくなります。 ローカルに保存された認証トークンは、運営者が該当ファイルを削除することで消去されます。

9. Cookieおよびアクセス解析

本ページはCookieを使用せず、アクセス解析ツールも設置していません。

10. 本ポリシーの変更

本ポリシーの内容を変更する場合は、本ページに変更後の内容と最終更新日を掲載します。
