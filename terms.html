利用規約

最終更新日：2026年8月19日

1. 適用

本規約は「KappaOS チャンネル分析ツール」（以下「本ツール」）の利用条件を定めるものです。 本ツールは運営者本人の個人利用を目的としており、第三者への提供を行っていません。

2. 利用条件

  • 本ツールは、利用者本人が所有・管理するYouTubeチャンネルに対してのみ使用できます。
  • 本ツールはYouTube APIサービスを利用しています。利用にあたっては YouTube 利用規約および Googleプライバシーポリシーが適用されます。
  • 本ツールは読み取り専用の権限のみを使用し、データの作成・変更・削除を行いません。

3. 禁止事項

  • 他人が所有するチャンネルのデータを取得する目的での使用
  • 取得したデータの第三者への提供、販売、公開
  • YouTube APIの利用規約に違反する使用

4. 免責

本ツールは現状有姿で提供されます。取得されるデータの正確性、完全性、 継続的な取得可能性について保証しません。YouTube API の仕様変更、 提供停止、その他の理由により本ツールが動作しなくなる場合があります。 本ツールの利用により生じた損害について、運営者は責任を負いません。

5. 規約の変更

本規約の内容を変更する場合は、本ページに変更後の内容と最終更新日を掲載します。
